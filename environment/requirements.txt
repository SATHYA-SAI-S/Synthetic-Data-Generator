# Privacy-Preserving Synthetic Healthcare Data Framework
# Pinned Requirements — Phase 2
# ============================================================
# Python version: 3.10.x (required; Opacus 1.x requires >=3.8, <=3.11)
#
# DP Library choice: Opacus (PyTorch ecosystem)
# Rationale:
#   - Opacus integrates directly with PyTorch autograd; no separate
#     computation graph required.
#   - Actively maintained by Meta with DP-SGD, per-sample gradient
#     clipping, and Renyi accountant built in.
#   - tensorflow-privacy was considered but rejected: it requires
#     TF2 which conflicts with the diffusion model architecture
#     (Phase 7 uses PyTorch-native diffusion). Mixing TF and PyTorch
#     in the same training loop introduces needless complexity.
#   - Opacus 1.4 adds support for BatchMemoryManager (critical for
#     Kaggle VRAM constraint) and virtual steps (gradient accumulation
#     under DP).
#
# All versions are pinned to the minor version. Patch updates are
# acceptable but must be validated against the setup_check.py smoke test.
